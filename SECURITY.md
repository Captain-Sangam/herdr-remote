# Security

## Report a vulnerability

Do not open a public issue. Use [private vulnerability reporting](https://github.com/Captain-Sangam/herdr-remote/security/advisories/new) on GitHub.

Include:

- what you found
- the steps to reproduce it
- the versions of herdr-remote, Herdr.app and Android.

## Scope

- **In scope:** `herdr-remoted`, the pairing flow, the Herdr mod and the Android app.
- **Out of scope:** Herdr.app, `hc`, Claude Code and Codex. Report those to their makers.
- Processes that run as the same macOS user are trusted ([ADR 0018](docs/adr/0018-trust-boundary.md)).
