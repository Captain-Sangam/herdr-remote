Two design systems for herdr-remote

Decision (9 November 2026): Pane. The rules are in DESIGN.md, the code is in android/app/src/main/java/dev/herdrremote/ui/theme/. The shortlist was Pane and Dispatch. Each system draws the same 18 screens with the same content, so you can compare them directly.

  • Each mockup is 412 × 915 dp, with the status bar and the 3-button navigation bar of the Galaxy S26. App content stays between the two bars. Turn on Show system bars to see the two zones.
  • Use Compare to see one screen in both systems side by side.
  • Click a phone to open it at full size. Use the arrow keys to move between screens and systems. Press Esc to close.
  • Use Theme to show all mockups in light or dark. Default shows each system in its main mode.
  • The mockups use macOS fonts as stand-ins. Each system names the open font to bundle in the app.

Screen Code States in the app Drawn as
App lock MainActivity.kt, Gate.kt, LockedScreen in App.kt Locked at start and after 5 min in the background. The system prompt asks for a biometric or the PIN. A note shows if the check fails. App lock
Notifications watch/WatchService.kt One alert for each blocked episode: "An agent needs attention". An ongoing notice: "Watching n agents" or "Connecting to the Mac…". The lock screen shows the public version only (SR-11). Notification on the lock screen
Pair PairScreen.kt Start (scan or paste). Connecting. Code shown, wait for Allow. Failed: denied, window closed, bad code, Mac not reachable. Pair: start. Pair: compare the code. Pair: failed.
Spaces (home) SpacesScreen in ListScreens.kt Loaded. First load. Not connected (stale banner with the age of the data). Could not load spaces. Spaces. Spaces: loading. Spaces: not connected.
Space SpaceScreen The agents of one space, with live status. Space
All agents AllAgentsScreen Blocked agents first. Empty: "No agents". All agents. All agents: empty.
Agent AgentScreen.kt, AgentViewModel.kt
  • Blocked, with a prompt that the phone can answer.
  • Refused: Mac in use, prompt changed, already answered.
  • View-only prompt.
  • Result notes: done, sent, not confirmed, uncertain, outcome unknown.
  • Transcript with "Load earlier", or terminal text with a hint.
  • Message composer, off while blocked.
  • Agent gone.
 Six agent mockups
Live view LiveView.kt Read-only terminal in colour, at the terminal size. Pinch to zoom. Agent: approved, live view
Settings SettingsScreen.kt Paired Mac endpoints, device id, background watching switch, a note when notifications are off, Forget this Mac. Settings

Three small states have no mockup of their own. Each one uses a pattern that the mockups show:

  • Pair connecting uses the wait pattern of the code screen.
  • Agent gone uses the empty pattern.
  • Notifications off uses the note pattern.
